## Description for adapting to the official form

**Proposed solution — informed inference:** BlackBox is a local industrial AI workbench that turns authorized documents into reviewable work products. An operator requests a result; the system plans the work, selects a compatible local model, retrieves source material, uses local tools and checks the resulting files. Intended outputs include approval notes, comparison spreadsheets, presentations, engineering calculations and executable code.

The differentiator is inspectable evidence: source references, recorded execution, file validation, explicit unresolved assumptions and bounded repair.
